# Aarix V2.1

Functional local/demo phase built on Aarix V2 Foundation.

Added:
- Local session flow after login/signup
- Home feed with local posts
- Like/unlike interactions
- Comment dialog with local comments
- Create post flow
- Profile editing
- Settings screen
- Privacy & Security screen
- Logout flow
- No ads
- No external packages

Important:
This is still a local/demo build. It does NOT provide real online authentication,
cloud database, media upload, or production account security. Those require a
backend and proper server-side authorization.
